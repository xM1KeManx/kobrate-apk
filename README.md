# Kobrate APK

Aqui vive solo el instalador de la app movil de Kobrate (sin codigo).

Descarga: https://github.com/xM1KeManx/kobrate-apk/raw/main/Kobrate.apk

El archivo siempre se llama Kobrate.apk y se reemplaza en cada version, para que el enlace no cambie.
Al abrirlo en Android hay que permitir instalar apps desconocidas la primera vez.
